## 三个必须先知道的硬事实

1. **`02-配置片段/board.toml-kernel-args-全文.txt` 里 46 条参数只有 4 条可移植**（且 `dby-touch` 在新板上**必须从 1 开始**，不是照抄本板的 8）
   （`dby-touch`、`dby-touch-se`、`sheng-touch-hid`、`dk`）。其余 42 条改的是显示（13 条）/存储（9 条）/OS-UI 与其它（18 条）/复位与日志（2 条）策略，
   照抄是**花屏最常见的原因**。
2. **`DbyTouchFw.h` 的固件只对工程号 W2599Z1100 验证过**。换 IC 变体时不要上传。
3. **`dby-touch=6` 会驱动复位脚**。若该脚在你的板子上是面板复位，会在这一级花屏——用 1023
   （不存在的脚）替换即可复测。

## 这一版相对上一版的改动

- 源码从 `-03a`（单接触）升级到 **`-03b`（多点）**：枚举全部 4 连通分量、全局最小距离配对、
  每接触独立 id 与抬起去抖、发布最多 10 个触点；
- 单分量判据**一个都没改**（连通性、2..80 节点、峰值 ≥1200、权重公式、质心公式全部保留）；
- 行 42 新增 `c=<触点数>` 前缀；
- 新增 `04-整合说明.md`、`05-进度汇报.md`；
- `02-配置片段/` 的 kernel_args 文件带**警告横幅**（上一版没有，这是花屏审计的首要发现）。
