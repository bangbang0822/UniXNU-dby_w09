# Superseded charging scope

This earlier draft proposed investigating Huawei's proprietary fast-charge path. On 2026-11-26 the owner changed the scope to standard USB-PD only, capped at the DBY-W09 published 22.5 W input rating. It is retained as a pointer so existing references remain understandable; it is no longer the active specification.

See [`charging-usb-pd-spec-2026-11-26.md`](charging-usb-pd-spec-2026-11-26.md) for the active plan.
