## Version comparison

The local core and public UniXNU have a common ancestor `dc8e5deb`; `git rev-list --left-right --count` reports 396 local-only and 633 public-main-only commits. This is a broad fork, not a safe fast-forward. The public iPadOS 17.7.11 OS profile still uses the same arm64/XNU line; the most consequential gap is integration and the GPU frontend: public main pins `UniXNU/metal2vulkan` runtime v2 and newer AdrenoMetal, while this fork pins `steelbrain/metal2vulkan` plus carried bridge patches. Public main adds a kernel/addon Adreno ABI identity check. Port that as a matched set only after the current cold build is reproducible.

The current device build branch and Gitee `main` have no Git merge base. Their current trees differ in ten tracked paths, especially `.github/workflows/package.yml`, `board.toml`, `porting.toml` and `unixnu.lock`. Gitee `main` has subsequent power record edits; the build branch has S0a/S0b instrumentation and cold-build workflow work. Treat them as two snapshots to reconcile, not as an ahead/behind count or a branch to merge blindly. `unixnu.lock` in the build branch also records more selected components than Gitee `main`.

R1 and R2 are confirmed defects in the reproducible-build/record workflow. R3 is a concrete failed input choice with a promising alternative, not an established fix. R4-R8 are compatibility or performance work with explicit hardware gates. No finding here justifies flashing a changed image without the repository's review and owner approval.
